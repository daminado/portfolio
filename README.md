# Portfólio de Daniel Moreira

Site pessoal de [Daniel Moreira](https://www.linkedin.com/in/danielmoreira-dev/), desenvolvedor front-end em Salvador (BA).

**No ar:** https://danielmoreira-dev.vercel.app

## O que tem aqui

- Cases de sites e sistemas para pequenos negócios (agendamento, painel administrativo, orçamento pelo WhatsApp)
- Demonstrações interativas que rodam no navegador: reserva com trava de horário, login, quadro kanban, regras de acesso e simulador
- Projetos com 3D em Three.js (carro em raio-X, prédio com régua de sol, implante dentário)

## Como foi feito

- HTML, CSS e JavaScript puro, com módulos ES e sem framework nem etapa de build
- Animações que respeitam `prefers-reduced-motion`
- SEO com canonical, Open Graph, JSON-LD (Person), sitemap e robots
- Publicado na Vercel

## Rodar localmente

Qualquer servidor estático serve, por exemplo:

```bash
npx serve .
```

Os dados das demonstrações são fictícios. As marcas dos clientes ficam preservadas.
